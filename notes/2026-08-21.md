# Tensor memory layout & strides
2026-08-21

## Findings

1. **Transpose does not copy.** `.t()` on a tensor just swaps its stride
   tuple and shape; the underlying storage (the 1D byte buffer) is
   untouched. A `(3,4)` contiguous tensor with strides `(4,1)` becomes,
   after `.t()`, shape `(4,3)` with strides `(1,4)` — same storage, same
   `data_ptr()`.

2. **What "non-contiguous" actually means.** A tensor is contiguous only
   when its strides match the row-major layout implied by its shape
   (i.e. `stride[i] = product of shape[i+1:]`). Transposing breaks that
   relationship without touching memory, so the result is non-contiguous
   even though nothing was copied.

3. **`.contiguous()` on an already-contiguous tensor is a no-op.** It
   returns the same tensor (same `data_ptr()`), no copy — confirmed, not
   just assumed.

4. **Serializer rule: don't branch on `is_contiguous()`.** Before pulling
   raw bytes out of a tensor for serialization, call `.contiguous()`
   unconditionally instead of writing `if not is_contiguous(): ... else: ...`.
   Since (3) is a no-op in the already-contiguous case, the branch buys
   nothing and only adds a code path to get wrong — see the bug below.

## Bugs

**`NameError` from a needless if/else.**

```python
if not New_Tensor.is_contiguous():
    New_Contiguous_Tensor = New_Tensor.contiguous()
    print("converted")
else:
    print("Is Contiguous: ", New_Contiguous_Tensor.is_contiguous())
```

`New_Tensor` was already contiguous, so the `if` branch (the only place
`New_Contiguous_Tensor` gets defined) never ran. The `else` branch then
referenced a name that doesn't exist:
`NameError: name 'New_Contiguous_Tensor' is not defined`.

Direct motivation for finding (4): the unconditional call removes the
branch that caused this.

## Core lesson

The kernel bug at the root of this — indexing with `i * ncols + j` —
silently assumes `stride = (ncols, 1)`. That assumption breaks for any
transposed/non-contiguous tensor, and fails without a crash: it just
reads valid memory with the wrong values.
