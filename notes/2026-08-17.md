# GPT-2 Weight Inspection Notes

## What I learned

* **Weight tying:** `lm_head.weight` and `wte.weight` are the same tensor. This is why `remove_duplicate=True` gives 148 tensors instead of 149.

* **`element_size()`:** gives the size of **one element**, not the whole tensor. Total memory is:
  `numel() * element_size()`.

* **HuggingFace `Conv1D`:** is basically a linear layer, not a real convolution. It stores weights as `(in, out)`, while `nn.Linear` uses `(out, in)`.

* **fp16:** cuts memory roughly in half without removing parameters, but uses less precision.

## Results

|                 | Tensors |  Parameters |      Size |
| --------------- | ------: | ----------: | --------: |
| No duplicates   |     148 | 124,439,808 | 497.76 MB |
| With duplicates |     149 | 163,037,184 | 652.15 MB |

`wte` is about **31% of the model**. In fp16, the weights would use about **248.88 MB**.

## Mistakes

* Used `element_size()` without multiplying by `numel()`.
* Converted to MB inside the loop instead of at the end.
* Left total `print()` statements inside the loop.
* Used the wrong conversion when calculating GB.

The biggest takeaway was understanding the difference between **parameters, tensors, and actual memory usage**.
